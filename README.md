# Sudoku GT

**Play in your browser:** https://USERNAME.github.io/REPOSITORY/

Or run it locally from this folder, then open http://localhost:8765:

```bash
python3 -m http.server 8765
```

## Requirements

- A modern browser: Chrome or Edge 105+, Firefox 114+ or Safari 16+
- Python 3, only for running it locally

There's nothing to install: the site has no packages or build step.
